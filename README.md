# Lucid
A TypeScript/JavaScript engine made for creating high-performance 3D web applications.

__Please note that this library is still under active development, and documentation is coming soon...__

Current Support:
- Extensible Asset Manager
- State Management
- WebGPU 3D Renderer
- Spritesheet Animation

Planned Support:
 - Mouse & Keyboard Input Handler
 - Custom Shader Pipeline
 - 3D Audio
